Publishing a batch

  1. Add pieces above, name them, tick categories, drag to order.
  2. Download renamed media — saves every file under its slug, plus an auto-captured poster frame for videos.
  3. Move those downloads into /Assets in your repo.
  4. Export works.json and replace the one at your repo root.
  5. Commit and push. Vercel redeploys and the new work appears.

Large video files bloat a git repo and Vercel's bandwidth. Anything over ~20 MB is better on YouTube or Vimeo as an unlisted link — use Add a video link for those.
